# See

See 是一个轻量级跨平台看图器原型，目标是替代系统默认图片查看器，优先强调：

- 启动快
- 切图快
- 界面极简
- 单张模式与长页浏览模式切换自然

## 当前 V1 范围

- Tauri 2 + Rust + TypeScript
- 无边框窗口
- 启动时接收图片路径
- 自动扫描当前目录中的主流图片文件
- 前端通过本地文件协议直接加载图片，避免 base64 带来的额外内存与编码开销
- 单张模式
- 左右方向键切图
- 滚轮切换上一张 / 下一张
- 双指缩放对应的浏览器缩放手势支持
- 长页模式
- 目录全部图片纵向连续排列
- 按 `Tab` 在单张与长页模式之间切换
- 邻近图片预加载与内存缓存
- “设为默认”入口
- 打包配置里的跨平台图片文件关联声明

## 项目结构

- `src/`: 前端界面与交互
- `src-tauri/src/lib.rs`: 启动参数、目录扫描、图片数据读取
- `src-tauri/tauri.conf.json`: 桌面窗口与打包配置

## 开发

### 1. 安装依赖

```bash
npm install
```

### 2. 启动开发模式

```bash
npm run tauri:dev -- "D:/path/to/example.jpg"
```

### 3. 打包

```bash
npm run tauri:build
```

## 默认应用集成说明

- Windows: `设为默认` 会把 See 注册到当前用户的 `RegisteredApplications` 和图片扩展关联能力中，然后打开系统“默认应用”设置；最终切换仍需用户确认。
- Linux: `设为默认` 会写入 `~/.local/share/applications/see.desktop`，并尝试对常见图片 MIME 执行 `xdg-mime default see.desktop ...`。
- macOS: 打包后的 app 会携带图片文档类型声明；`设为默认` 会尝试打开系统设置入口，但最终默认打开方式通常仍需用户在 Finder 里确认。
